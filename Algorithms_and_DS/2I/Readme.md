в функции int main() мы записываем данные, далее к собранному массиву применяем LsdSort.

в функции LsdSort() мы создаем цикл из 8 обходов в каждом из которых применяется ByteSort над нашем массивом по определенному байту (в ByteSort мы передаем номер байта по которому следует сортировать). Мы сортируем с последнего байта для сохранения стабильности сортировки (сохранения порядка одинаковых данных в котором они были даны).

в функции ByteSort() мы применяем "стабильную сортировку", она состоит в применении "сортировки подсчетом" где в качестве массива диапазона мы берем массив cnt[256].
