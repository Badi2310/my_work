в функции int main() мы записываем данные, после чего создаем кучу. Далее используем быстрый ввод, а затем парсим введенные строки.
Сами же элементы кучи являются парами в которых в первой части мы храним данные, а во второй индекс запроса(при какой по счету операции он был введен).

Куча реализованна стандартно, несмотря на не значителный изменения, а именно на массив ans{0}. В нем мы будем хранить номера узлов в которых лежит конкретный элемент (т.е. например, элемент {5, 8} будет лежать в ячейки массива(кучи) под номером ans[8] (обратите внимания что при создании масива массив ans инициализируется как массив 1 длины)) 
при вызове каждой функции getMin, extractMin, decreaseKey в конец массива ans добавляется 0 (это нужно для сохранения валидности массива ans), а при insert в конец массива ans добавляется i (номер запроса insert)

getMin работает стандартно 
decreaseKey полсе уменьшения какого то элемента выполняет над ним SiftUp
SiftUp меняет желемент с родителем если сам элемент меньше родителя, при этом происходит
swap(ans[data.[родитель].second], ans[data[ребенок].second]) (для сохранения валидности массива ans).
SiftDown проверяет существует ли у родителя дети. Если оба ребенка есть, то сохраняем индекс минимального ребенка, если существует токо левый то сохраняем его в индес минимального ребенка, если детей нет, то выходим из функции. Далее если родитель больше ребенка, со свапаем их и 
swap(ans[data.[родитель].second], ans[data[ребенок].second]) (для сохранения валидности массива ans).
