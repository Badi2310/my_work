в первой части функции int main() "36-42 строчки" мы записываем условие, после используем функцию FindLength().

в функции FindLength() мы ищем длину алгоритма с помощью "Бинарного поиска" :

(1 случай, когда разница границ не превосходит 1) проверяем на пригодность значение right (т.к. нам нужно максимальное значение).
если оно не подходит то возвращаем left (это значение будет ответом, т.к. алгоритм привел нас к двум значениям, одно из которых является ответом, а right не подходит).

(2 случай, когда разница границ превосходит 1) проверяем на пригодность значение left + (right - left) / 2, если оно подходит то щначит ищем дальше в диапозоне (left + (right - left) / 2, right) т.к. мы знаем что значение left + (right - left) / 2 подходит и значит значение меньше него нас не интересуют, иначе ищем ответ (left, left + (right - left) / 2).

в функции CheckIfSuits() мы проверяем значение на пригодность lenght для ответа:

садим первого фестрала в первое стоило, после садим каждого следующего фестрала в стоило которое находится на растоянии не меньшим чем lenght от стоило куда посадили предыдущего фестрала, если мы смогли рассадить всех фестралов (т.е. count в какой-то момент прировняется к 0) то это значение подходит и возвращаем true, иначе false.
