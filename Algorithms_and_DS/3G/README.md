заводим два числовых указателя на концы массива и приближаем их следующим образом:

если под правым указателем лежит число больше того что лежит под левым указателем то тогда двигаем левый указатель на право покак не встретим число больше предыдущего, по мере прохода по массиву мы обновляем наш ответ.
аналогично в другом случае. Алгоритм работает за O(1) от доппамяти так как ипользуется лишь два указателя (массив который передается на вход вродебы не считается за доппамять, иначе нам не будет известно где находится наивысшая высота)
