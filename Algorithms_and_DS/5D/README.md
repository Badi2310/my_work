В начале мы запустили DFS для обычного графа graph для того чтобы получить порядок выхода вершин. После, в убывающем порядке начали запускать DFS в "транспонированном графе" graph_t по порядку убывания времени выхода вершин из изначального графа. Таким образом мы смогли пронумеровать компоненты сильной связности в возрастающем порядке(в порядке который требовался в контесте)
