 заводится вектор векторов vec размера К. В каждом его векторе хранится отсортированный вектор. Сортируем его используя merge по порядку для каждой его пары векторов, после О(logK) таких действии размер vec станет = 1, и в нем будет лежать единственный вектор который будет хранить наш ответ.

 Merge работает за линию, по этому на каждом уровне тратится О(S) времени, итогавая ассимптотика равна O(SlogK)
