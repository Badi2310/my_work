заводим для строки P хэшмапу где будеем хранить информацию о его элементах (сколько всего той или иной буквы в содержании Р)
заводим очередь для подстроки, размера как у Р (чтобы порядок букв не сбивался) и тоже для нее заводим хэшмапу.

храним дополнительные параметры diff_counter который равен количеству разных букв в строке Р и same_counter равный количеству совподающих наборов букв в строке Р и в текущем положении очереди (к примеру у строк аввссс и аааввс совпадает только набор букв в => same_counter = 1).

после каждого сдвига очереди по строке Т параметр same_counter определенным образом обнавляется, и если в какой то момент same_counter == diff_counter то значит анаграмма нашлась, в противном случае не нашлась.

алгоритм удовлетворяет условиям 4 баллов так как в памяти используется только очередь и хэшмапы которые занимают О(|P|) памяти. и работает для алфавита размера 10^9 так как используется хэшмапа и она хранит только встретившиеся ранее буквы.
