Visitor и DFS были взяты с примера прикрепленному к требованиям ревью.

Добавил наследника Visitor - "CompDFSVisitor" для работы с компонентами связности, сделан по аналогии с TimerDFSVisitor.
Он хранит "текуший индекс компоненты", "количество компонент" и хэш мапу где ключь - номер компоненты, значение - вершины компоненты.

Алгоритм работает благодаря алгоритму DFS.
